# GitHub

Connect a GitHub repository to Cinatra and let your agents work with it. Once you sign in and pick a repository, Cinatra keeps a local copy so workflows that need repository content can read from it, and any agent or workflow that needs to write to GitHub picks up the same connection.

## Capabilities

- Sign in to GitHub and authorise Cinatra to act on your behalf
- Browse the repositories your GitHub account can see
- Pick the active repository Cinatra should work with
- Make the connected repository available to any agent or workflow that needs it
